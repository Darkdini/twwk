# Мирта — встроенный ИИ-агент для игры Миртана

Кнопка **🧠 ИИ-советник** в профиле игрока открывает чат с собственным
ИИ-агентом по имени **Мирта**.

Главное: агент **полностью автономный**. Никаких внешних API, ключей,
платных сервисов и интернета — всё «мышление» выполняется прямо на твоём
сервере, на чистом Node.js, без единой новой зависимости. Это не бот
«привет-привет»: у него есть разбор намерения вопроса и видимый «ход
мыслей».

## Что умеет

| Возможность | Примеры |
|---|---|
| 🧮 **Математика** (рекурсивный спуск) | `(12+3)*4`, `2^16`, `корень из 144`, `5!`, `sqrt(16)+2^3` |
| 💯 **Проценты** | `15% от 200`, `10 это сколько процентов от 50` |
| 📐 **Перевод величин** | `5 км в мили`, `2 кг в фунты`, `100 C в F`, `3 часа в минуты` |
| 🗓 **Дата и время** | `какой сегодня день`, `который час`, день недели для даты |
| ⚔ **Советы по игре** (по реальным формулам `game.js`) | `что мне строить дальше?`, `сколько у меня ресурсов`, `стоит ли воевать орками?` |
| 📚 **База знаний** | наука, космос, география, столицы, история |

Каждый ответ снабжён сворачиваемым блоком **💭 ход мыслей** — это шаги
рассуждения агента (определение намерения, разбор выражения, поиск в базе
и т.д.), то есть видимый «потенциал мышления».

Для советов по игре агент читает реальное состояние игрока (раса, ресурсы,
уровни зданий) и считает стоимость следующего уровня по той же формуле, что
и сама игра (`базовая × 1.6^уровень`), поэтому советы не выдуманные.

> Честная граница: это офлайн-движок, а не большая языковая модель. На
> вопросы, которых нет в его базе знаний, он **не выдумывает** ответ, а
> честно говорит об этом и предлагает переформулировать или посчитать.

## Установка

### Вариант А — патчем (рекомендуется)
Из корня проекта Миртана (где лежит `server.js`):

```bash
cp /путь/agent.js ./agent.js
patch -p1 < mirtana-ai.patch
```

### Вариант Б — вручную
1. Скопируй `agent.js` в корень проекта (рядом с `server.js`, `game.js`).
2. В `server.js`:
   - после `const G = require('./game');` добавь
     `const AI = require('./agent');` и две `Map` для истории/анти-флуда;
   - в обработчике `client.onMessage` добавь ветку `m.type === 'ai-chat'`.
3. В `public/index.html`:
   - кнопку `#pp-own-ai` в сетку профиля и обработчик клика → `openAIChat()`;
   - ветку `m.type==='ai-chat'` в `ws.onmessage` → `aiReceive(msg)`;
   - функции `openAIChat / aiSend / aiReceive / aiBubble / aiAppend / aiFmt`.

(Все эти изменения уже собраны в `mirtana-ai.patch`.)

После установки просто перезапусти сервер — новых зависимостей нет.

## Как это работает

```
профиль → 🧠 ИИ-советник
        → openAIChat()  (модалка чата)
        → ws.send({type:'ai-chat', text})
сервер  → client.onMessage: AI.ask(text, {player, history})
        → agent.js: намерение → (математика | проценты | конвертер
                                | дата | совет по игре | база знаний
                                | честное рассуждение)
        → ws.send({type:'ai-chat', msg:{text, steps}})
клиент  → aiReceive() рисует ответ + «ход мыслей»
```

Анти-флуд: не чаще одного запроса в 1.2 секунды на игрока. История диалога
(12 последних реплик) хранится в памяти per-player.

## Файлы
- `agent.js` — движок агента (≈0 зависимостей, ~430 строк).
- `mirtana-ai.patch` — изменения `server.js` и `public/index.html`.
