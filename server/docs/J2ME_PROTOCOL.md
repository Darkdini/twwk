# Протокол J2ME-клиента (2D, сборка 28092009x3) — референс

Источник: `Third_World_War_of_Kings_2D_1.jar`, Fenix-Soft, MIDP-2.0/CLDC-1.0,
ноябрь 2009. Декомпиляция CFR (`j2me/src`, не в git).

> ВНИМАНИЕ: это **более старое поколение протокола**, чем Android 3D 2.0.112.
> Живой сервер говорит на Android-протоколе (см. PROTOCOL.md / OPCODES.md).
> Этот документ — Rosetta stone: концепции, кодировки, дизайн логина.

## Внешний кадр (FLAP, как OSCAR/ICQ) — класс `x.d()` / `x.a()`
```
[0]   0x2A (42)        маркер
[1]   channel (1..5)
[2-3] seq    (int16 BE)
[4-5] length (int16 BE)  — длина payload
[6..] payload
```
Каналы:
- `1` → класс `f` (коннект/логин)
- `2` → корневой `d` (данные)
- `4` → (резерв)
- `5` → пинг (`new x(null,5)`)

## Внутреннее сообщение — корневой класс `d`
`d(channel, type, subtype, data)`; диспетчер `g.a(d)` свитчит `type` → `subtype`.

## Порядок байт — big-endian (класс `g`)
- запись: `g.a(arr,off,val)`=byte; `g.a(arr,off,val,true)`=int16 BE;
  `g.a(arr,off,long)`=int32 BE.
- чтение: `g.a(arr,off)`=u8; `g.b(arr,off)`=int16 BE; `g.c(arr,off)`=int32 BE.

## TLV-поле — класс `ab.a(tag, baos, bytes)`
```
[tag:int16 BE][len:int16 BE][value: len байт]
```

## Логин — `g.d()`
Тело (TLV), затем пакет `d(1, 4, 5, body)`:
```
tag 1 = login    (lowercase)
tag 2 = password (lowercase)
```

## Рукопожатие версии — `g.a(d)` (channel 1, type 1, sub 0)
Сервер инициирует → клиент отвечает:
- `d(1,1,1, [i.a:int16][i.b:int16])`
- `d(1,1,0, "28092009x3")`  ← версия-токен сборки

## Кириллическая кодировка — `g` (та же, что в Android 3D)
`168→Ё 184→ё 165→Ґ 170→Є 175→Ї 178→І 179→і 180→ґ 186→є 191→ї`,
`192..255 → +848` (CP1251-подобная). Совпадает с `y/AbstractC0612d` в 3D.

Рынок, Кузнец, Конюшня, Посольство, Академия магов, Караульная башня…).
Карта игрового контента для нашего сервера.
