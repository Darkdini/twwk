# TLWK server

Свой сервер для веб-клиента **TLWK** (`tlwk.ru`, Vue SPA). Реализует API по
**захваченному контракту** (`../server/docs/tlwk_api_capture.txt`,
`../server/docs/TLWK_API.md`): регистрация/логин с **JWT**, замок, ресурсы,
здания, карта, профиль и т.д. Чистый Node, без зависимостей. Состояние — в
`state.json`.

## Что уже работает
`/api/captcha · register · login · user · castle/res · castle/info ·
building/prepare · create · upgrade · map` — возвращают формы, как у боевого
сервера (проверено реальными запросами клиента). Остальные эндпоинты —
заглушки `{success, data}`, наполняем по мере надобности.

## Запуск (Termux / ПК)
```bash
# 1) положить фронтенд (графику + index.html) из захвата:
./setup.sh /sdcard/Download/assets.zip /sdcard/Download/tlwk/tlwk_capture.txt
#    (или вручную: распаковать ассеты в public/assets/, index.html в public/)

# 2) запустить
node server.js          # PORT=7777 по умолчанию
```
Открой `http://localhost:7777` — отдаётся захваченный Vue-клиент, который ходит
в наш API.

## Как клиент попадает на сервер
- **Браузер на телефоне:** просто открой `http://localhost:7777`.
- **WebView-приложение TLWK:** нужен билд, где URL указывает на наш сервер
  (патч `MainActivity` URL → `http://127.0.0.1:7777/app/game`). Скажи — соберу.

## Замечания
- `public/` (графика + JS-бандл) — это контент TLWK, в git не коммитим;
  наполняется из твоего захвата (`setup.sh`).
- Это первый каркас: цель — чтобы клиент дошёл до игры. Логику (стоимость
  зданий, рост ресурсов, бой) наращиваем в `server.js` — она наша.
- Альтернатива: влить этот API-слой в твою **Mirtana** (тот же жанр/стек).
