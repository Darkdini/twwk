# ⚔️ Третий мир — Война Королей (браузерный клон)

Самодостаточный браузерный клон стратегии **«Третий мир: Война Королей»**.
Никакого сервера и сборки — **открой `index.html` в браузере и играй**.
Прогресс сохраняется автоматически в `localStorage`.

## Как запустить

**Вариант 1 — просто открыть файл**
Дважды кликни по `game/index.html` (или перетащи в браузер).

**Вариант 2 — локальный сервер** (рекомендуется на телефоне)
```bash
cd game
python3 -m http.server 8000
# открой http://localhost:8000
```

## Что есть в игре

- **4 народа** со своими бонусами: Люди 🛡️, Эльфы 🏹, Гномы ⛏️, Орки ⚔️.
- **6 ресурсов**: золото, дерево, камень, еда, железо, люди — добываются в реальном времени.
- **Город 🏰** — 14 зданий с уровнями, стоимостью, требованиями и временем постройки
  (ратуша, склад, фермы и рудники, рынок, казарма, конюшня, мастерская, кузница, стена, капканщик).
- **Армия ⚔️** — обучение 9 типов войск (пехота, стрелки, конница, осадные орудия)
  и 5 военных/экономических технологий в кузнице.
- **Мир 🗺️** — карта 11×11 с лагерями разбойников и ИИ-королевствами.
  Отправляй войска в поход или разведку, веди бои, забирай добычу.
- **Бой** учитывает атаку/защиту/HP, бонусы рас, стены и технологии.
- **Отчёты 📜** — журнал событий: стройка, обучение, исследования, итоги сражений.

## Механика (кратко)

| Система | Как работает |
|---|---|
| Производство | Здания дают ресурсы/час, копятся каждую секунду до лимита склада |
| Строительство | Стоимость и время растут с уровнем; уровень зданий ограничен Ратушей |
| Обучение | Тратит ресурсы и население; высокий уровень здания ускоряет обучение |
| Поход | Скорость зависит от самого медленного юнита, расы и технологии «Логистика» |
| Бой | Сумма атаки против суммы защиты (×стена ×раса), потери по доле урона |
| Добыча | Победитель уносит ресурсы в пределах грузоподъёмности армии |
| Голод | Если еда уходит в минус — войска дезертируют |

## Структура

```
game/
  index.html      — разметка (стартовый экран + игра)
  style.css       — оформление (тёмно-золотая тема, адаптив под телефон)
  js/
    data.js       — данные: расы, ресурсы, здания, юниты, технологии
    engine.js     — движок: состояние, экономика, стройка, бой, мир, сохранение
    ui.js         — интерфейс: экраны Город/Армия/Мир/Отчёты, ввод
    main.js       — точка входа: создание королевства, игровой тик
```

Логика полностью на клиенте — править баланс можно прямо в `js/data.js`.
